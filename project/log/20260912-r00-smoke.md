## 验证过的 perf agent 标准用法（照抄即可）
```bash
# 采集 (guest 内, root): 事件配置 /mnt/smoke_guest.cfg (模板在 $PROJ/results/r00/)
/home/ppw/vm/gssh '(cd /root && ./tracebox -c /mnt/<cfg>.cfg --txt -o /mnt/<out>.pftrace &) && sleep 1 && <workload>'
# 分析 (host):
$TP -q query.sql /home/ppw/bench/share/<out>.pftrace
```
SQL 要点: 原始 tracepoint 事件在 **ftrace_event 表**（不在 slice 表）:
- `select name, count(*) from ftrace_event group by name;`
- 归因: `select t.name, count(*) from ftrace_event e join thread t using(utid) where e.name like 'mmap_lock%' group by 1;`
- 竞争指标口径: start_locking(尝试加锁) vs acquire_returned(拿到) vs released(释放);
  fork/mmap/munmap 的语义区分在 include/trace/events/mmap_lock.h 的 mode 字段(事件 arg)。
