# VMA 完全移除路线图（2026-10-08, 用户重申裁决后立项）

## 0. 裁决变更（推翻既有口径）

用户重申：**堆/栈/vdso/vvar/动态库也必须移除 VMA——最重要是完全移除 VMA**。
按 #13 自身条款（"除非未来新指令轮推翻"），本指令即该推翻轮：
- #13 的"永久边界/永续登记"措辞**废止**（hint 迁移窗口语义仍不实施——收编走
  原址, 不迁移）;
- D33 的"无共享臂"降级为**待建缺口**（不再是终态依据）;
- V-E.1/W-3b/W-6b 的"合同内住户"分类改为**待迁移清单**。
- E2 二期（A/B/C 退役分支）不受影响——审计机械在任何终态下都是死重。

## 1. 为什么这些还在（根因, 如实）

| 住户 | 现状 | 当初不收编的裁决 | 缺口实质 |
|---|---|---|---|
| 动态库（wl_file, ~9-70 VMA/进程, **最大头**） | mmap_base 原址, 树上 | #13: 非零 hint 永不达 addr==0 路由; 收编需"hint 迁移窗口", 违 T0 | **伪缺口**: region 机械不依赖窗口地址——**原址收编**（loader 选好的地址不动, VMA 换成 region）即可, 无需迁移语义。真缺口 = declare/fault/zap/fork 机械的"窗口域限定"放宽到任意用户地址 |
| 主二进制段 | 同 wl_file | 同上 | 同 V1 |
| 堆初始段（wl_brk_vmas=1） | start_brk 漏斗 | V-E.1 | W-3 seed 机械已在（PR-0 同族）, exec 时直接 seed |
| 栈（wl_stack） | GROWSDOWN 原址 | W-3b | 缺 GROWSDOWN 扩展臂（向下生长 fault 语义） |
| vdso/vvar/vclock（wl_special） | special_mapping 家族 | W-6b | 缺只读特殊页 region 臂（vvar=内核共享数据, 只读语义单一） |
| MAP_SHARED 写穿透 | punch 登记形 | D33 | 真硬缺口: 多进程共享写臂（最后做/按需裁决） |

根因总结: **我把各时点裁决的"边界"措辞当成了终态**, 本周的 commit 对齐的是
mv3e 台账口径（审计机械退役 = 窗口域零 VMA 的收尾）, 而非"全地址空间
arena 化"的终极目标。#13 留了推翻口, 本指令触发。

## 2. 分期路线（每组一枚 PR, 沿用 E2 门口径）

- **V1 库+主二进制原址收编**（最大头）: 采纳路由的地址门从"窗口域"放宽为
  "任意用户地址"（原址 declare, 无 placement）; fault 快/慢路径、zap、fork
  镜像、exit 走查的去窗口化。验收: wl_file 桶消失, /proc/maps 双源零差异,
  电池全绿。估 2-4 枚 PR。
- **V2 堆初始段 + 栈**: exec 时堆 seed（复用 PR-0 机械）+ GROWSDOWN 扩展臂。
  估 1-2 枚。
- **V3 special 家族**: 只读特殊页 region 臂（vdso 文本可执行 + vvar 只读）。
  估 1 枚。
- **V4 门卫收敛**: MODE mm 的 create_vma 总闸（任何新 VMA 即 BUG——此时
  E3 门卫从"分流守卫"变为"不可达断言"）; VMA 层仅存 =off 世界。J6 终账。
- **MAP_SHARED 写臂**: 独立大件, V4 后单独立项裁决。
